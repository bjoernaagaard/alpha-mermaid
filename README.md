# alpha-mermaid

An Effect-native Mermaid renderer for SVG and terminal output.

The project is in its initial migration stage. pnpm manages dependencies and development commands. Published library and CLI output targets Node.js and browsers.

Track scope, phase status, exit criteria, and risks in the [migration plan](MIGRATION.md).

## Development

```bash
pnpm install
pnpm check
```

Use these focused commands while developing:

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```
